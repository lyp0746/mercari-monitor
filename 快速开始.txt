【给客户发送软件的两种方式】

  ★ 方式一：桌面版 EXE（最简单！推荐！）

     打包步骤（开发者操作）：
     ┌────────────────────────────────┐
     │ ① 双击 "打包发布.bat"         │
     │ ② 选择 [1] 打包桌面版 EXE     │
     │ ③ 等待 5-15 分钟              │
     │ ④ 找到 dist\二手监控助手.exe  │
     └────────────────────────────────┘

     发送给客户：
     - 只需要发这一个 EXE 文件！
     - 客户双击就能运行
     - 不需要安装任何东西！

     客户使用：
     → 双击 EXE 文件即可启动
     → 首次启动可能需要解压几秒钟
     → 默认账号：admin / admin123


  ★ 方式二：网页版（功能更完整）

     适合：懂一点电脑的客户 / 需要远程访问的场景

     操作步骤：
     ① 把整个项目文件夹发给客户
     ② 让客户双击 "一键启动.bat"
     ③ 浏览器自动打开 http://localhost:5173

     详细教程见："网页版部署指南.txt"


【遇到问题？】

  ✗ EXE报错"找不到python311.dll"？
     → 原因：之前打包的是文件夹模式，你只发了EXE
     → 解决：重新用新的脚本打包（单文件模式）
     → 步骤：双击"打包发布.bat" → 选[1] → 等待完成

  ✗ 客户说完全不会操作？
     → 发网页版 + "快速开始.txt" + 录制30秒视频

  ✗ 想要自定义图标或版本信息？
     → 编辑 build.py 中的 icon 和 version 参数


【文件清单】

  开发者用的：
  ├─ 打包发布.bat      ← 打包EXE给客户
  ├─ 一键启动.bat      ← 本地测试网页版
  ├─ 环境检查.bat      ← 检测开发环境
  └─ build.py          ← 打包配置（可自定义）

  发给客户的：
  ├─ 二手监控助手.exe   ← 桌面版（单文件）
  ├─ 或整个项目文件夹   ← 网页版
  ├─ 快速开始.txt       ← 给客户的说明书
  └─ 网页版部署指南.txt ← 详细教程
