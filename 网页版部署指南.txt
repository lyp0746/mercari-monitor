      煤炉助手 - 网页版 零基础部署指南
              （给不懂电脑的客户专用）
═══════════════════════════════════════════════════════

【重要提示】
✓ 本指南专为不懂技术的用户设计
✓ 只需跟着做，不需要理解原理
✓ 每一步都有截图说明的位置
✓ 全程大约需要 10-15 分钟

───────────────────────────────────────────────────────
第一步：准备工作（必须先做！）
───────────────────────────────────────────────────────

1. 确认你的电脑是 Windows 系统（Windows 10/11 都可以）

2. 你需要一个解压软件（如果已有可跳过）：
   - 推荐使用：Bandizip 或 7-Zip（免费）
   - 或者 Windows 自带的也可以

3. 确保硬盘有至少 2GB 的空闲空间

───────────────────────────────────────────────────────
第二步：安装必要软件（只需装一次）
───────────────────────────────────────────────────────

【A】安装 Python 运行环境（必须）

1. 打开浏览器，访问：
   https://www.python.org/downloads/

2. 点击黄色按钮 "Download Python 3.11.x"
   （注意：要选 3.11 版本，不要选 3.12 或 3.13）

3. 下载完成后，双击安装文件
   ★ 重要：安装时一定要勾选最下方的
          "Add Python to PATH" 选项！

4. 点击 "Install Now" 或 "Install Now (with default settings)"
   等待安装完成（约 2-3 分钟）

5. 安装完成后点击 "Close"

6. 验证安装是否成功：
   - 按 键盘上的 Win + R 键
   - 输入 cmd 回车（会打开黑色命令窗口）
   - 输入：python --version
   - 如果显示 Python 3.11.x 就成功了
   - 关闭这个黑窗口


【B】安装 Node.js（用于网页界面）

1. 打开浏览器访问：
   https://nodejs.org/

2. 点击左侧的 LTS 版本下载（推荐版本）
   （LTS = 长期支持版，更稳定）

3. 下载完成后双击安装
   - 一路点击 "Next" 即可
   - 保持默认设置不变

4. 安装完成后重启电脑（这一步很重要！）


【C】安装 uv（Python 包管理器）

1. 重启电脑后，再次打开命令提示符（Win+R → 输入 cmd → 回车）

2. 复制这行命令并粘贴到黑窗口中，然后回车：
   powershell -Command "irm https://astral.sh/uv/install.ps1 | iex"

3. 等待安装完成（几秒钟）

4. 关闭黑窗口


───────────────────────────────────────────────────────
第三步：启动程序（每次使用都要做的）
───────────────────────────────────────────────────────

方法一：一键启动（推荐！最简单）

1. 找到项目文件夹中的 "一键启动.bat" 文件
   （.bat 文件显示为齿轮图标）

2. 双击它！

3. 会自动弹出几个窗口：
   - 第一个窗口：自动安装依赖（首次需要几分钟）
   - 第二个窗口：启动后端服务
   - 第三个窗口：启动前端界面
   - 浏览器会自动打开

4. 看到 "服务已启动" 提示后，就可以使用了！

5. 使用完毕后：
   - 直接关闭所有弹出的窗口即可停止


方法二：手动启动（如果一键启动失败）

1. 打开命令提示符（Win+R → cmd → 回车）

2. 依次输入以下命令（每行输入完按回车）：

   cd Desktop\mercari-monitor
   （注意：把 Desktop\mercari-monitor 改成你实际的路径）
   
   uv run uvicorn src.api.main:app --port 8000
   
   【不要关闭这个窗口！保持打开状态】

3. 再打开一个新的命令提示符窗口（重复 Win+R → cmd）

4. 输入：
   cd Desktop\mercari-monitor\web
   npm run dev

5. 打开浏览器访问：http://localhost:5173


───────────────────────────────────────────────────────
第四步：开始使用
───────────────────────────────────────────────────────

1. 首次打开会看到登录页面
   默认账号：admin
   默认密码：admin123

2. 登录后你会看到主界面，包含：
   - 首页：统计信息和最新商品概览
   - 发现：监控到的商品列表，点击卡片查看详情
   - 监控：管理监控关键词
   - 订单：代购/代拍订单管理 ⭐新功能
   - 平台：各平台账号配置 ⭐新功能
   - 收藏：收藏感兴趣的商品
   - 设置：配置监控参数

3. 基本操作流程：
   ① 在"监控"页面添加你想监控的商品词
   ② 在"设置"页面选择监控平台、设置刷新频率
   ③ 点击"开始监控"
   ④ 在"发现"页面查看监控结果
   ⑤ 点击商品卡片查看详情和费用明细 ⭐新功能
   ⑥ 一键代购/代拍心仪商品 ⭐新功能
   ⑦ 在"订单"页面管理订单状态 ⭐新功能


───────────────────────────────────────────────────────
常见问题解答（FAQ）
───────────────────────────────────────────────────────

Q1: 双击 "一键启动.bat" 后一闪而过？
A1: 右键点击该文件 → 以管理员身份运行

Q2: 提示 "uv 不是内部或外部命令"？
A2: 说明第二步的[C]没做好，重新执行一遍

Q3: 提示 "node 不是内部或外部命令"？
A3: 说明第二步的[B]没做好，确认已安装 Node.js 并重启了电脑

Q4: 启动后浏览器打不开或显示错误？
A4: 
    - 检查是否有杀毒软件拦截
    - 尝试手动在浏览器输入 http://localhost:5173
    - 确保端口 8000 和 5173 没被占用

Q5: 页面能打开但是没有数据？
A5:
    - 先检查"关键词"页面是否添加了监控词
    - 在"设置"页面确认已点击"开始监控"
    - 查看右侧日志面板是否有报错信息

Q6: 如何修改登录密码？
A6:
    - 目前需要在代码中修改（暂时不支持界面修改）
    - 联系开发者获取帮助

Q7: 可以在其他电脑上使用吗？
A7: 可以！只要那台电脑也安装了上述软件，
    把整个项目文件夹复制过去就行

Q8: 监控的数据存在哪里？
A8: 
    - 数据存储在本地的 data\monitor.db 文件中
    - 位于项目根目录
    - 备份这个文件就能备份所有数据
