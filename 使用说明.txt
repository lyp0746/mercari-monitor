    煤炉助手 - 使用说明
═══════════════════════════════════════════════

【软件简介】
本软件是一款多平台二手商品实时监控系统，支持9大平台：
  • Mercari JP（日本）🟢稳定
  • Yahoo! Auctions（日本）🟢稳定
  • 駿河屋 Surugaya（日本）🟢稳定 ⭐新增
  • 楽天市場 Rakuten（日本）🟢稳定 ⭐新增
  • Yahoo!ショッピング（日本）🟢稳定 ⭐新增
  • PayPay フリマ（日本）🟡不稳定
  • Fril (Rakuma)（日本）🟡不稳定
  • Bunjang 번장（韩国）🟢稳定
  • Carousell（新加坡/香港/台湾/马来西亚/菲律宾/澳洲）🔴较慢

主要功能：
  ✓ 极速轮询 - 最快0.3秒一次搜索（默认0.3秒）
  ✓ 智能冷却 - 连续失败自动暂停，避免浪费资源
  ✓ 智能筛选 - 价格、成色、商城过滤、黑名单
  ✓ 一键全选平台/成色 - 新增关键词更便捷
  ✓ 一键代购/代拍 - 点击商品详情直接下单 ⭐新功能
  ✓ 订单全流程管理 - 从下单到签收完整追踪 ⭐新功能
  ✓ 平台账号管理 - 配置各平台Cookie/Token ⭐新功能
  ✓ 费用明细透明 - 自动计算服务费、运费、预估总价 ⭐新功能
  ✓ Bot命令 - Telegram直接管理监控任务
  ✓ Discord通知 - Embed格式推送，团队协作友好
  ✓ 降价提醒 - 实时监控价格变动
  ✓ 拍卖通知 - 雅虎拍卖临近结束提醒
  ✓ 关注系统 - 卖家标记 + 商品留言更新推送
  ✓ 多币种汇率 - 支持8种货币转换
  ✓ 登录验证 - 管理员账号保护

═══════════════════════════════════════════════
一、环境准备
═══════════════════════════════════════════════

1. 安装Python 3.11或更高版本
   下载地址：https://www.python.org/downloads/
   安装时勾选"Add Python to PATH"

2. 安装uv包管理器（推荐）

   Windows系统（PowerShell）：
     powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

   Linux/macOS系统：
     curl -LsSf https://astral.sh/uv/install.sh | sh

3. （仅Web端需要）安装Node.js 18+
   下载地址：https://nodejs.org/

二、启动软件
═══════════════════════════════════════════════

方式1：桌面端（推荐）
  命令：uv run python run_desktop.py

方式2：Web端
  命令：uv run python run_web.py
  然后访问：
    前端界面：http://localhost:5173
    后端API：http://localhost:8000

方式3：无头模式（服务器专用）
  uv run python src/main.py --headless -k "关键词@平台"

默认登录账号：
  用户名：admin
  密码：admin123

⚠ 首次登录后请立即修改密码！

═══════════════════════════════════════════════
三、基本使用
═══════════════════════════════════════════════

1. 登录系统
   启动后会弹出登录窗口，输入默认账号密码登录

2. 添加监控关键词
   • 点击左侧"关键词"菜单
   • 点击右上角"+ 添加关键词"按钮
   • 填写信息：
     - 关键词：要搜索的商品名称
     - 目标平台：✅ 默认所有平台都选中，可取消不需要的
     - 价格范围：设置最低和最高价格（可选）
     - 轮询间隔：搜索频率（秒），留空使用默认值(0.3秒)
       范围：0.3-60秒，建议0.3-2秒
     - 高级选项：
       ☑ #noshops# 过滤商城卖家（屏蔽官方店铺）
       ☑ 成色筛选 ✅ 默认全选，可取消不需要的成色
          （全新/几乎全新/非常好/良好/可接受/较差）
       ☑ 降价提醒 ✅ 默认开启，价格下降时推送通知

3. 开始监控
   • 点击顶部"开始监控"按钮
   • 软件会自动按设定频率搜索各平台
   • 发现新商品会在主界面显示
   • **同时自动启动Telegram Bot服务**

4. 编辑/删除关键词
   • 在关键词列表选中一行
   • 使用底部按钮：
     ✏️ 编辑选中 - 修改关键词设置
     🗑️ 删除选中 - 删除关键词
     ⏯️ 启用/禁用 - 暂停/恢复监控
     🔄 刷新列表 - 重新加载

═══════════════════════════════════════════════
四、Telegram Bot命令 ⭐重点功能
═══════════════════════════════════════════════

【功能介绍】
配置好Telegram后，可以直接在Telegram中发送命令管理监控任务，
无需打开软件界面！非常适合手机远程操作。

【启用条件】
1. 在设置中正确填写Token和Chat ID
2. 启动监控（Bot会自动激活）
3. 在Telegram中向你的Bot发送命令

【基础命令】

/help          显示所有可用命令和帮助信息
/status        查看当前监控状态概览
/test          发送测试消息验证连接
/start         显示欢迎信息和快速开始提示

【关键词管理】

/add <关键词> [平台]        添加新的监控关键词
示例：
  /add canon                添加关键词"canon"，使用默认平台
  /add ps5 mercari_jp      添加关键词"ps5"，指定Mercari平台
  /add 相机 bunjang        添加中文关键词到Bunjang平台

/remove <关键词>           删除指定关键词
示例：/remove canon

/keywords                  列出所有当前监控的关键词

【卖家管理】

/watch <卖家ID> [平台]      关注指定卖家
示例：/watch 710134275

/unwatch <卖家ID>          取消关注卖家
示例：/unwatch 710134275

/sellers                   列出所有关注的卖家

【黑名单管理】

/bseller <卖家ID>          屏蔽指定卖家（不推送其商品）
示例：/bseller 710134275

/unban <卖家ID>            取消屏蔽卖家
示例：/unban 710134275

/bword <词语>              屏蔽包含该词的商品
示例：/bword 假货

/unbword <词语>            取消屏蔽词语
示例：/unbword 假货

/blacklist                 查看所有黑名单（屏蔽的卖家和词语）

【信息查询】

/list                      显示完整配置摘要（状态+关键词+卖家+黑名单）

【平台代码参考】
mercari_jp       Mercari日本
bunjang          Bunjang韩国
paypay_fleamarket PayPayフリマ
fril             Fril/Rakuma
yahoo_auctions   Yahoo!拍卖
carousell        Carousell

【实际使用场景】

场景1：收到推送后发现是垃圾卖家
→ 直接回复：/bseller 卖家ID
→ 结果：该卖家商品不再推送

场景2：临时想加个热门关键词
→ 发送：/add 新品上架
→ 结果：立即开始监控该关键词

场景3：想知道当前监控了多少东西
→ 发送：/status
→ 结果：显示关键词数、关注卖家数、轮询间隔等

场景4：看到太多假货信息
→ 发送：/bword 假货
→ 结果：标题含"假货"的商品不再推送

五、代购/代拍功能 ⭐新功能
═══════════════════════════════════════════════

【功能介绍】
  发现心仪商品后，可以直接在系统内一键下单，
  无需跳转到原始平台操作！

【代购流程】（普通商品）
  1. 在首页或发现页浏览监控到的商品
  2. 点击商品卡片打开详情弹窗
  3. 查看费用明细：
     • 商品价格（自动换算为人民币）
     • 服务费（商品价 × 8%）
     • 日本国内运费（¥60预估）
     • 国际运费（到仓后计算）
     • 预估总计
  4. 点击「🛒 一键代购」按钮
  5. 系统自动创建订单

【代拍流程】（雅虎拍卖专用）
  1. 发现拍卖商品后点击卡片
  2. 详情弹窗会显示「拍卖」标签
  3. 点击「🔨 一键代拍」按钮
  4. 系统创建代拍订单

【订单管理】
  在「📦 订单」页面可以：
  • 按状态筛选订单（待确认/代购中/已购买/等）
  • 查看每个订单的费用明细
  • 推进订单状态
  • 删除订单

  订单状态流转：
  待确认 → 已确认 → 代购中 → 已购买
  → 日本国内已发货 → 已到仓库 → 国际物流中 → 已签收

  任何阶段都可以取消订单（已签收除外）

【平台账号配置】
  在「🌐 平台」页面可以：
  • 为每个平台配置登录凭证
  • 添加Cookie和Token
  • 管理多个账号

  配置步骤：
  1. 点击右上角「＋ 添加账号」
  2. 选择平台
  3. 输入账号名称
  4. 粘贴从浏览器获取的Cookie
  5. 可选填Token
  6. 点击添加

六、高级功能

【降价提醒】

  方式1：在软件界面添加（见第三部分）
  方式2：通过Telegram命令 /watch 卖家ID
  关注的卖家发布的商品会优先显示，带⭐标记

【关注商品留言】
  1. 在"关注列表"选择"关注商品"标签
  2. 添加要关注的商品ID
  3. 系统会定期检查该商品的留言/议价情况
  4. 有新留言时会重新推送通知

  方式1：在设置页面手动添加（每行一个卖家ID）
  方式2：通过Telegram命令 /bseller 卖家ID

  设置位置：设置 → Telegram配置
  步骤：
  1. 在Telegram找@BotFather创建Bot，获取Token
  2. 找@userbot获取自己的Chat ID
  3. 填入Token和Chat ID
  4. 点击"测试发送"验证
  5. 保存设置

  推送消息格式示例：

  *✨新商品上架*

  🏷 商品名称
  💰 ¥10,000 ≈¥470
  📊 成色: 良好
  🌐 平台: 🇯🇵 Mercari JP
  🔑 关键词: 搜索词
  ⏱ 上新时间: 2024-07-15 12:30:00
  ⏳ 延迟: 5秒前

  [🔗 查看商品](链接地址)

【Discord通知配置】⭐新功能
  设置位置：设置 → Discord 推送配置
  步骤：
  1. 打开目标Discord频道
  2. 点击频道名称旁的⚙️齿轮图标（频道设置）
  3. 选择"整合"(Integrations)标签页
  4. 找到"Webhooks"区域，点击"新建Webhook"
  5. 自定义Webhook名称和头像（可选）
  6. 复制Webhook URL（格式如 https://discord.com/api/webhooks/...）
  7. 在软件设置页面粘贴URL到"Webhook URL"输入框
  8. 点击"🔗 测试连接"按钮验证
  9. 保存设置

  Discord消息特点：
  • 使用Embed格式展示，信息结构清晰
  • 不同事件用不同颜色标识：
    - 🔵 新商品上架（蓝色）
    - 💛 降价提醒（黄色）
    - 🔴 拍卖结束（红色）
    - 🟢 留言更新（绿色）
  • 自动显示商品图片
  • 支持点击跳转到商品页面

  💡 提示：
  • Telegram和Discord可以同时启用
  • 适合团队协作场景，多人共享同一频道
  • 可以在多个Discord频道创建不同Webhook

【自定义汇率】
  支持货币：日元(JPY)、韩元(KRW)、新加坡元(SGD)、
           港币(HKD)、台币(TWD)、马币(MYR)、
           澳元(AUD)、菲律宾比索(PHP)

  所有价格会自动换算为人民币显示

【代理IP配置】
  如果需要使用代理（推荐用于高频监控）：
  设置位置：设置 → 代理IP配置
  格式示例：
    http://user:pass@proxy.example.com:8080
    socks5://proxy.example.com:1080
  每行填写一个代理地址

  特性：
  • 自动跳过失效代理
  • 所有代理失效时自动重置
  • 日志显示当前使用的代理状态

七、性能优化建议
═══════════════════════════════════════════════

【轮询间隔设置指南】

网络环境良好（日本/韩国服务器）：
  高频关键词（限量款）：0.3-0.5秒
  普通商品：0.3秒（默认值）
  冷门商品：0.5-1秒

普通网络（国内服务器）：
  推荐：0.5-2秒
  最小不建议低于0.3秒

网络不稳定：
  建议：2-5秒
  开启智能冷却（默认开启）

【最佳实践】

1. 关键词分类
   根据重要程度设置不同轮询间隔

2. 平台选择
   只选择需要的平台，避免无效请求

3. 价格过滤
   设置合理价格范围，减少返回数据量

4. 商城过滤
   开启#noshops#可大幅减少数据量和请求次数

5. 成色筛选
   勾选需要的成色，避免无关结果

6. 代理IP池
   高频监控强烈建议配置多个代理IP
   自动轮换避免被封禁

【预期性能】

单次请求响应时间（参考）：
  Mercari JP: ~500-800ms（Turbo模式自动加速）
  Bunjang: ~95ms
  PayPay: ~150ms
  Fril: ~180ms
  Yahoo Auctions: ~200ms
  Carousell: ~250ms

错误恢复机制：
  第1次失败：等待0.2秒重试
  第2次失败：等待0.24秒
  第3次失败：等待0.29秒 + 自动切换代理
  连续失败：关键词冷却（暂时跳过）

九、常见问题
═══════════════════════════════════════════════

Q: 首次启动报错？
A: 删除以下文件夹后重试：
   Windows: rmdir /S /Q .venv __pycache__
   Linux: rm -rf .venv __pycache__

Q: 忘记管理员密码？
A: 删除 data\monitor.db 文件重启即可
   默认账号恢复为 admin / admin123

Q: 打包失败？
A: 依次执行：
   uv run python build.py --clean
   uv pip install --upgrade -e .
   uv run python build.py --desktop

Q: EXE文件太大？
A: 正常现象，包含Python运行时。
   可用UPX压缩减小约30-50%体积。

Q: 监控速度慢？
A: 检查以下几点：
   1. 轮询间隔是否过大（建议0.3-0.5秒）
   2. Mercari平台Turbo模式已自动加速
   3. 是否配置了代理IP
   4. 同时监控的关键词是否过多
   5. 网络延迟是否正常

Q: 被平台封禁？
A: 解决方案：
   1. 使用代理IP轮换
   2. 降低请求频率
   3. 开启智能冷却（默认开启）
   4. 减少单IP请求量
   5. 使用#noshops#减少请求

Q: Telegram Bot没反应？
A: 排查步骤：
   1. 确认Token和Chat ID正确无误
   2. 点击"测试发送"验证配置
   3. 确认已启动监控（Bot随监控启动）
   4. 在Telegram中发送 /help 测试
   5. 检查日志是否有Bot相关错误

Q: 日志显示很多错误？
A: 正常现象，说明：
   1. 可能被限速或封IP（自动切换代理）
   2. 关键词冷却中（避免浪费资源）
   3. 网络波动（自动重试）
   
   只要还能收到新商品推送就说明正常运行
